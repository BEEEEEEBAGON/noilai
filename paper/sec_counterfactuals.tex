\section{Orthographic Counterfactuals}
\label{sec:counterfactuals}

The re-encoding arms hold meaning and information fixed and change only the code points, hence the token sequence, so a difference between arms is caused by tokenization and by nothing else about the item. For arm $a$ on model $m$ the estimand is the within-item average treatment effect $\tau_m(a) = \mathbb{E}_i[Y_i(a) - Y_i(\mathrm{base})]$ over the sampled items, identified without assumptions beyond the representativeness of the item sample, because the same item is scored under both arms with prompt, paraphrase, decoding and engine fixed. We run C1 (NFD) and C1$'$ (the partially composed form) on \noilai{} and on the 500 Vietnamese test items of XCOPA \citep{ponti-etal-2020-xcopa}, whose text is pure NFC in the older placement convention so that every arm is a genuine re-encoding of it, and C2 (placement) on the C2-enriched \noilai{} set only, since it touches 43 of the 500 XCOPA items and is unpowered there at any affordable size (those items are reported descriptively in the appendix at most); C3 strips information and is a contrast, not a counterfactual. XCOPA's items may have been memorized in one spelling, so every effect estimated there is re-estimated on fresh \noilai{} items.

\paragraph{Pre-registered hypotheses.}
\hyp{4} (\emph{the rarer convention costs}) leads, because both placement conventions are common in Vietnamese text, so C2 is in-distribution in both directions and distribution shift cannot explain its effect: rewriting affected items into the placement convention that is rarer in the reference corpus (expected: the newer one; the direction is fixed by a corpus count before any model run) lowers accuracy on those items in models generally, whatever their normalizer, because the rarer spellings are rarer in training text; the claim is the pooled estimate with the number of models whose Holm-adjusted interval excludes zero, and an equivalence test with a 2-point margin for the rest, never ``in every model''. \hyp{3} (\emph{a crossover}): in models whose tokenizer passes NFD through, $\tau_m(\mathrm{NFD})$ is positive on \task{T1} \var{3}, because NFD makes the tone an explicit symbol the model can move, and negative on XCOPA, because the same change produces longer and rarer sequences; a pure count account predicts harm in both places. The default explanation the crossover must beat is distribution shift: NFD is out-of-distribution text (XCOPA-vi and the pretraining web are overwhelmingly NFC; under the Gemma~3 tokenizer the NFD sequence is longer for 92\% of words, carries 59\% more tokens per syllable and has alignment 0.27), so a uniform drop under NFD across \var{1}--\var{4} and XCOPA is reported as out-of-distribution sensitivity, not as evidence about sub-syllabic access. The claim rests on both pooled estimates across pass-through models being on the predicted side, the per-family table is primary, and with fewer than five informative families the pooled interval is labelled unreliable and \hyp{3} is decided by the per-family intervals; normalizing tokenizers are the negative control with an effect of exactly zero. \hyp{3b} (\emph{tone isolation}): in Gemma~3, the NFD gain on \var{3} is larger on items whose tone mark becomes a token of its own than on matched items whose mark stays attached (a difference in differences), and the same contrast on \var{1}, which does not move tones, is near zero.

\paragraph{Does the effect track token count or the tone symbol?}
Within one tokenizer, re-encoding an item changes its token sequence deterministically, so token count is a coarsening of the intervention rather than a mediator, and the ``share of the effect mediated by token count'' the founding plan asked for is not an identified quantity; we do not estimate it. Instead, four pre-registered analyses ask whether the count mechanism can account for the effect. First, effect modification: $\tau_m$ as a function of the item's token-count change, adjusted for baseline difficulty, the number of tone and quality marks, syllable frequency and length, variant, lexicality, glide and spelling trigger, labelled associational, since the count change is nearly the number of diacritics. Second, the zero-dose contrast within a tokenizer, items whose count does not change but whose ids do against items whose count grows, reported where the stratum holds at least 100 items per model (realistic for C2 and for vocabularies with NFD pieces, nearly empty for byte-level C1). Third, the three-arm ordered contrast baseline $<$ PC $<$ NFD in token count: if accuracy tracks the extra tokens, PC sits between the two; if NFD moves accuracy beyond what its extra tokens predict, an explicit tone symbol is operating. Fourth, the encoding $\times$ character-spacing $2 \times 2$ from the input-format condition, where spacing saturates the token count for both encodings. \placeholder{Figure~\ref{fig:deltatok}: the effect of re-encoding by token-count-change stratum, by encoding form, and under character spacing, per model.}
