\paragraph{Generator.}
The parser maps a syllable to (onset, glide, nucleus, coda, tone) and the speller maps it back under the rules of Appendix~\ref{app:rules}; parsing is a spelling round trip, so \vi{céo} (for \vi{kéo}) is a recognized misspelling, not a syllable. Legality is attested, not generated: a structure is legal when its onset plus rime occurs in the Hunspell vi\_VN inventory \citep{hunspell-vi} with some tone and its tone respects the stop-coda constraint. The engine computes all six outputs per base pair, drops illegal ones and those equal to the input or its reversal, merges duplicates with their variant labels, and screens outputs, readings and candidates against a vulgarity blocklist (applied to an input only when the input pair itself is a taboo phrase). \vi{qu}- inputs, whose analysis changes the swap, are excluded pending a native check (Appendix~\ref{app:construction}).

\paragraph{Three tasks.}
\textbf{\task{T1} (transformation)} gives a two-syllable input and the name and step-by-step definition of a variant and asks for the unique output; the \emph{strict} score requires the output structures in the named order, the \emph{lenient} score accepts the unordered pair. \textbf{\task{T2} (decoding)} gives a nói lái form and withholds the variant, since every variant undoes itself; the gold is every lexical reading under any of the six variants in either order, natively validated for the core. \textbf{\task{T3} (validity)} pairs each correct \task{T1} output with an invalid twin that shares the input and differs in one component (another variant's output, an onset, a rime, a tone, or a misspelling that keeps the structure), so that a model ignoring the question scores 50\%; spelling twins are reported apart from the headline.

\paragraph{Sampling and splits.}
Lexical base pairs are two-syllable entries of a 74k-word list with both syllables attested (47,535 candidates); pseudo-pairs are quota-sampled from attested syllables so that their joint distribution over tone-pair class, stop coda, spelling trigger, glide and zero onset matches the lexical pairs', leaving lexicality as the difference. The pool is split \emph{by base pair} into a public development set (20\%) and a gated test set. Open models run a stratified \emph{main sample} of 4,200 test items, 350 per task $\times$ variant cell, which contains the \emph{core} of 125 items per cell (\task{T3}: 62 yes/no pairs), the only \noilai{} data an API model sees; a separately built set of 500 pseudo-pair items, disjoint from the release by base pair and every one changed by the placement arm, serves that arm alone.

\paragraph{Freeze and hashes.}
Release v0.3 is built from the stage-1 pre-registration commit on a clean tree (\placeholder{stage-1 commit hash}); its identity is the SHA-256 of its items with the canary removed (\texttt{92d332e5\ldots}), and the main and placement-arm samples are fixed files with their own hashes, verified before every run (Appendix~\ref{app:construction}). The build seed is not published: development and test items are drawn and split from one seeded stream, so a public seed would regenerate the gated test split. Test files carry a canary \citep{srivastava-etal-2023-beyond,2023-emnlp-main-308}, of whose GUID the paper prints only the SHA-256, and a sealed split is never sent to any API.

\paragraph{Attested examples.}
Folk and literary nói lái are collected from published collections with their sources. Some attested forms need a regional merger (\vi{vẫn như cũ} for the rule's \vi{vẫn như củ}) or bend a vowel for meaning (\vi{độc hại} for \vi{đọc hại}). Rows therefore carry a three-valued tag, exact, approximate by a named merger, or approximate by a named substitution. All rows enter \task{T2}; only exact two-syllable rows enter \task{T1}-style scoring and the memorization analysis. The seed holds \nAttested{} rows, \nAttestedExact{} exact and \nAttestedApprox{} approximate, \nAttestedVerified{} of them native-verified so far; the target is 200--400 verified rows from at least three collections.

\paragraph{Validation protocol.}
Three adult native speakers judge correctness, spelling, lexicality and offensiveness on a 1,000-item probability sample, every core \task{T2} gold set and every attested row, two per item and all three on 200; agreement is Krippendorff's $\alpha$ \citep{krippendorff-2011-computing,J08-4004} with raw agreement and Gwet's AC1, and a confirmed generator bug forces regeneration before any model run. About twenty adult volunteers form a human baseline on 246 main-sample items with the models' prompt (Appendix~\ref{app:validation}). \placeholder{Validation results: $\alpha$, raw agreement and AC1 per judgment with CIs; generator precision per cell; number of items changed.}
