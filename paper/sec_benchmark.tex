\section{The \noilai{} Benchmark}
\label{sec:benchmark}

\noilai{} is generated and scored by a rule engine that encodes the structure and spelling rules of Section~\ref{sec:background}; Table~\ref{tab:counts} gives the counts, every headline size is reported with its number of base pairs, and Appendices~\ref{app:build} and~\ref{app:validation} hold the build and validation details.

\subsection{Parser, speller and legality}
\label{sec:engine}
The parser maps a syllable to (onset, glide, nucleus, coda, tone) and the speller maps a structure back to standard orthography under the rules of Appendix~\ref{app:rules}; parsing is a spelling round trip, so \vi{céo} (for \vi{kéo}) is rejected in strict mode and recognized in lenient mode as a misspelling. Legality is attested, not generated: a structure is legal when its onset plus rime occurs with some tone among the 6,595 parsable syllables of the Hunspell vi\_VN list \citep{hunspell-vi} (plus 261 word-list syllables that reuse an attested rime) and its tone respects the stop-coda constraint. The \vi{i/y} alternation and either tone-mark placement are accepted on input and canonicalized (\placeholder{emitted \vi{i/y} convention confirmed with the validators}). We treat the \vi{u} of \vi{qu} as the glide, as phonology does; school grammar treats \vi{qu} as an onset, the two analyses give different swaps, and no attested example settles it, so \vi{qu}- syllables are excluded from generated inputs pending a 20-pair native check.

\subsection{Three tasks}
\label{sec:tasks}
A \emph{base pair} is two syllables $(A, B)$; the generated variants are the component permutations of Table~\ref{tab:variants}. \textbf{\task{T1} (transformation)} gives a two-syllable input and the name and step-by-step definition of a variant, and asks for the output; the gold is unique. The \emph{strict} score requires the output syllables' structures in the named order; the \emph{lenient} score, a secondary number, accepts the unordered pair, so that a traditional onset-swap answer to a \var{4} item is wrong strictly and right leniently. \textbf{\task{T2} (decoding)} gives a permuted form, a generated permutation or an attested nói lái, and asks what phrase it hides. Since every variant undoes itself, naming it would collapse \task{T2} into \task{T1}; the prompt withholds it, and the gold is the set of every lexical reading of the input under any of the six variants in either order (the base pair is always one; the number of readings is a covariate). Lexicality is dictionary membership plus native validation of every core item's gold set; a legal answer outside the gold set is binned as plausible-non-gold, and the variant applied is scored over the three unordered classes $\{\var{1},\var{6}\}$, $\{\var{2},\var{3}\}$, $\{\var{4},\var{5}\}$. \textbf{\task{T3} (validity)} pairs each correct \task{T1} output with an invalid twin that shares the input and differs in one component type: another variant's output when its string is distinct, a changed onset, rime or tone, or a \vi{c/k}, \vi{g/gh} or \vi{ng/ngh} misspelling; the model judges whether the candidate is the correct output of the named variant. Yes and no items share an input, so the set is balanced by construction; spelling twins test orthographic convention rather than sub-syllabic access, so the headline \task{T3} number excludes them and reports them separately (\placeholder{observed yes-rate per model}).

\subsection{Sampling, splits and freeze}
\label{sec:sampling}
Lexical base pairs are two-syllable entries of a 74k-word list whose syllables are both attested (\releaseNLexicalPairsAvailable{} candidates); pseudo-pairs are quota-sampled from attested syllables so that their joint distribution over zero onset, glide, stop coda, spelling trigger and tone-pair class matches the lexical pairs', leaving lexicality as the only difference (achieved shares and shortfalls are in the manifest). Filters run in a fixed order with drop counts per cell: legality and the round trip; outputs equal to the input or its reversal; duplicate strings, merged under the set of variant labels that produce them; a blocklist screen for vulgar readings on outputs, readings and candidates, and on an input only when the input pair itself is a taboo phrase; overlap with the attested set or the demonstration pairs; and the \vi{qu}-, \vi{p}-onset, marginal-rime and loanword exclusions. Over \releaseNBasePairs{} base pairs (\releaseNLexicalBasePairs{} lexical, \releaseNPseudoBasePairs{} pseudo) the six variants produced 15,000 candidates, of which \releaseDropIdentity{} were the identity, \releaseDropReversal{} the reversal and \releaseDropIllegal{} illegal. Every item carries the covariates of every regression: lexicality of input and output, word-list syllable frequency (a corpus frequency is joined at scoring time once the reference corpus is fixed), the structural strata, whether tones, onsets or rimes coincide (the \emph{degenerate} stratum, excluded from any variant-vs-variant claim) and whether the placement convention affects it.

The pool is split \emph{by base pair} into a public development set (\releaseDevPercent{}\%; \releaseNDev{} items) and a gated test set (\releaseNTest{} items). Open models run on a stratified \emph{main sample} of \releaseNMain{} test items (\releaseMainPerCell{} per task $\times$ variant cell, the size that resolves a 10-point paired contrast at 80\% power at up to 46\% discordance before the design effect, which the pilot measures and which may raise $n$; \placeholder{realized design effect}) containing the balanced \emph{core} of \releaseNCore{} items (125 per cell; \task{T3}: 62 yes/no pairs), the only \noilai{} test items an API-served model sees (a provider whose tier trains on inputs instead receives a development-derived set of the same shape, reported separately); a separately built placement-enriched set of \releaseNCtwo{} pseudo-pair items, disjoint from the release by base pair, serves the C2 arm. Blocklist-flagged items (\releaseNVulgar{}) go to the gated split with their base pairs. Every test file carries the BIG-bench canary sentence in a header record and every test item the canary GUID and do-not-train flags \citep{2023-emnlp-main-308,srivastava-etal-2023-beyond}; the paper prints only the GUID's SHA-256 (Table~\ref{tab:hashes}), the GUID itself living in the gated README, dataset card and file header, so that a hit detects benchmark rather than PDF contamination. The build seed is not published: development and test items are drawn and split from one seeded stream, so a public seed would regenerate the gated split; the released generator mints new instances, the gated file, identified by its content hash, is the reference instance, and a sealed split with another seed and canary is never sent to any API. Contamination is a weak threat to a generator that can mint a fresh test set but a real one for the attested subset, which a guided-instruction probe tests \citep{2308.08493}.

Every run reads one frozen release, \releaseVersion{}, built on \releaseBuiltOn{} by the generator at commit \releaseGeneratorCommit{} from a \releaseGitDirty{} tree and identified by the SHA-256 of its item files with the canary fields removed, \texttt{\releaseContentShaShort{}}\ldots{} (Table~\ref{tab:hashes} adds the digests of the split files and the two seeded samples, of the attested strings frozen before the build and of the look-up resources; the derived subsets a run reads are hashed in the run plan). Generator, build, scoring and extraction are fixed by the stage-1 pre-registration commit (\placeholder{stage-1 hash}), hypotheses and analysis plan by the stage-2 commit before any test-split run (Appendix~\ref{app:prereg}); a validator-confirmed generator bug triggers a full regeneration before any model run, with a new identity.

\subsection{Attested examples}
\label{sec:attested}
Folk and literary nói lái are collected from published collections into a seed table with input, output, the engine-derived set of variant labels (\var{1}--\var{6}) that reproduce it, glosses, confidence, a vulgarity flag and the source. Not every example is a pure rule output: some reach a real word only under a regional merger, some bend a vowel or tone for meaning (\vi{độc hại} `toxic' for the rule's \vi{đọc hại}). Rows carry a three-valued tag, \emph{exact}, \emph{approximate by a named merger} or \emph{by a named substitution}, checked by a test; every row enters \task{T2} with the attested gold, but only exact two-syllable rows enter \task{T1}-style scoring and the memorization analysis (\hyp{6}), and attested inputs and outputs are reserved out of the generated pool. The seed holds \nAttested{} rows, \nAttestedExact{} reproduced exactly and \nAttestedApprox{} approximate, \nAttestedVerified{} of them native-verified (counts generated from the release file); the target is 200--400 rows from at least three cited collections, all verified, and \hyp{6} is tested only if at least 100 verified exact two-syllable rows exist at the data freeze.

\subsection{Validation and human baseline}
\label{sec:validation}
Three adult native speakers, one per region if possible, judge a 1,000-item probability sample with known stratum weights, every core \task{T2} gold set, every attested row, the 20-pair \vi{qu}- check and a 20-pair ``which variant do you produce?'' item that region-tags the variants, answering whether the output is correct under the variant, spelled acceptably, a real word or phrase, and offensive. Each item gets two validators and a 200-item overlap all three; we report Krippendorff's $\alpha$ \citep{J08-4004} with raw agreement and Gwet's AC1 beside it, because high prevalence depresses $\alpha$ (Appendix~\ref{app:validation}), MASI and Jaccard distances for the set-valued \task{T2} gold \citep{L06-1392}, and generator precision per cell with an interval from the weighted sample. About twenty adult native speakers each complete a 30-item form (six anchors seen by everyone, 24 items each seen by exactly two people; 246 items from the main sample) with the same p0 prompt and demonstrations as the models and a ten-item block of attested \task{T2} items as the cultural reference. Because most generated outputs are pseudo-phrases, this baseline measures natives following linguistic instructions on rule-generated permutations; the comparator is \emph{mean-human} accuracy with ``any human correct'' as a ceiling, and at $\pm$4--5 points it is a reference band, not a cell-level or ``superhuman'' comparison. Volunteers are unpaid adults who consent in writing (the Ethical Considerations section). \placeholder{Validation results: $\alpha$, raw agreement and AC1 per judgment with CIs; generator precision per cell; items changed.}
